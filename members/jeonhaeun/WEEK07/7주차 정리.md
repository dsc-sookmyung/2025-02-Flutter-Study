- Navigator.push :
  - 현재 화면 위에 새 화면을 쌓아서 이동하는 함수
  - 페이지 이동할 때 사용하는 기본 방식

```dart
                      Navigator.push(
                        context,
                        MaterialPageRoute(
                          builder: (context) {
                            return CityScreen();
                          },
                        ),
                      );
```

- Navigator.pop :
    - 현재 화면을 닫고 이전 화면으로 돌아가는 함수
    - push로 쌓았던 화면을 하나 제거하는 동작
```dart
onPressed: () {
                    Navigator.pop(context);
                  },
```
