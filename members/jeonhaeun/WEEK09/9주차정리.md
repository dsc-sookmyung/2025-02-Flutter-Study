### Container

- ####  color + decoration 동시에 사용 불가
  - Container에 color와 decoration.color를 동시에 지정하면 충돌이 발생한다.

```dart
Container(
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.only(
      topLeft: Radius.circular(20.0),
      topRight: Radius.circular(20.0),
    ),
  ),
)
```


- #### Container를 아래로 밀고 싶을 때

1) height 설정
```dart
Container(
  height: 300,
)
```

2) Expanded 사용
- Column 안에서 남은 공간을 자동으로 차지하도록 함.

```dart
Expanded(
  child: Container(),
)
```

### State(상태)

state: 사용자 인터페이스를 구성하는 모든 변하는 값.

- #### Local State
  - 특정 위젯 내부에서만 쓰는 상태  
  - 관리와 수정이 쉬움

- #### Global State
  - 앱 전역에서 공유하는 상태  

---

### StatefulWidget vs StatelessWidget

- #### StatelessWidget
  - 내부에 상태 없음  
  - 변화가 필요하면 기존 위젯을 버리고 재생성

- #### StatefulWidget
  - 별도의 State 객체를 통해 값이 유지됨  
  - 값이 변하면 setState로 UI를 다시 그림

---

### setState()

```dart
setState(() {
  isChecked = true;
});
```

- 해당 블록에 포함된 변화만 화면에 반영됨  
- StatefulWidget 내부에서만 사용
