# ElevatedButton

- 명확한 의도를 가진 액션 버튼

- 주로 저장, 추가, 완료 같은 실행 중심 기능에 사용

- 사용자가 입력 → 확인 → 저장 흐름으로 인식하기 적합

- 기존 RaisedButton, FlatButton을 대체하는 modern 버튼

### 스타일 지정 방법

```
ElevatedButton(
  onPressed: () {},
  style: ElevatedButton.styleFrom(
    backgroundColor: Colors.blue,
  ),
  child: Text("Add"),
);
```

- color: 속성이 아닌 style: 내부에서 지정해야 함


# State (상태)

UI를 구성하는 데이터이면서 변할 수 있는 값

UI는 해당 값이 변경될 때 자동으로 다시 렌더링됨

```
bool isChecked = false;

setState(() {
  isChecked = true;
});
```

# Checkbox

- value: true → 체크됨

- value: false → 체크 안 됨

반드시 상태 변수와 연결되어야 함

```
Checkbox(
  value: isChecked,
  onChanged: (value) {
    setState(() {
      isChecked = value!;
    });
  },
);
```

# StatefulWidget vs StatelessWidget

- StatefulWidget : 상태 변화에 따라 UI가 변경

ex) Checkbox, Toggle, Form Input

- StatelessWidget : 상태 변경 없음, 단순 표시

ex) Text, Icon, 기본 구조 UI

상태 변화 흐름 : Widget → State 객체 → 사용자 행동 → setState() 호출 → UI 업데이트
