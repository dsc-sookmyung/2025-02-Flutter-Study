# JSON을 해독해 API 응답에서 값 가져오기

## API 공급자 포맷
XML 포맷
- 키(태그) - 쌍(값)의 집합체

JSON 포맷
- 자바스크립트 객체와 유사
- {key:value}

*날씨 데이터는 JSON 포맷

*JASON Viewer Awesome을 설치하면 json 데이터를 포맷화해서 볼 수 있음


## 데이터 출력하기
- AndroidManifest.xml 파일에서 실행
- 하나의 화살표를 접었을 때 나오는 것이 items 리스트
- json 화면에서 경로를 복사하고 쓰는 것이 편함

```
var longitude = jsonDecode(data)['coord']['lon'];
var weatherDescription = jsonDecode(data)['weather'][0]['description'];
```

- 변수형을 var로 설정하는 이유 : jsonDecode(data)가 dynamic 유형이라서(어떤 변수가 올지 모름)

## NetworkHelper

- 초기화할 때 url를 넘김
- 그 url을 이용해 http get 요청을 만듦
- response 반응 확인 -> 성공적이면 jsonDecode를 이용해 데이터를 디코딩하고 필요한 곳으로 보냄

## 사용자가 직접 입력한 도시의 날씨 정보 가져오기

```
Future<dynamic> getCityWeather(String cityName) async {
    NetworkHelper networkHelper = NetworkHelper('$openWeatherMapURL?q=$cityName&appid=$apiKey&units=metric');
    var weatherData = await networkHelper.getData();
    return weatherData;
  }
```
