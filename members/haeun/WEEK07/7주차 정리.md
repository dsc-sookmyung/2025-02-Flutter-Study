## 1️⃣ JSON 구조 & jsonDecode 이해 (강의 147)

**JSON 형식의 특징**

- API 응답은 대부분 JSON 사용 (Rest API 표준 형태).
- `{ key: value }` 구조로 데이터 제공.
- key는 메타데이터, value는 실제 값.

**JSON → Dart 변환**

- `jsonDecode`를 사용해 **JSON 문자열을 Map/List 형태로 파싱**.
- JSON의 리스트 구조는 **index로 접근 가능**.
  - 예: `weather[0]['description']`

**핵심 포인트**

- JSON 내부 값 접근: `decoded['weather'][0]['id']`
- JSON Viewer Pro로 데이터 구조 시각화 가능.

## 2️⃣ OpenWeather API 요청 흐름 (강의 148)

**기본 흐름**

1. 위치 정보 가져오기 (`Location` 클래스).
2. 위도/경도를 담은 URL 생성.
3. HTTP GET 요청 후 JSON 응답 받기.
4. jsonDecode로 파싱 후 필요한 값 추출.

**HTTP 응답 코드 이해**

- `200` 성공
- `401` API 키 인증 오류
- `422` 잘못된 요청 (파라미터 null/포맷 오류)

**로직 분리의 중요성**

- API 호출 로직을 `networking.dart` 로 분리 → 재사용 가능.

## 3️⃣ LoadingScreen → 네트워크 & 위치 연동 (강의 148)

**화면 초기 흐름**

- `initState()` → 위치 조회 → 날씨 API 호출
- 위/경도 기반으로 URL 자동 생성

**핵심 이해**

- 화면에서는 단순히 데이터 요청만 관리하고,
- 요청/파싱 로직은 `NetworkHelper`로 옮겨 구조 유지.

## 4️⃣ 비동기 로딩 UI 적용 (강의 149)

**필요성**

- 위치 조회 + 네트워크 통신은 시간이 걸림
- 사용자 경험(UX) 개선 필요

**사용 패키지**

- `flutter_spinkit`
  → 로딩 화면에서 스피너 표시

**Navigator 흐름**

- `push()` → 새 화면 스택에 추가
- `pop()` → 현재 화면 제거 후 이전 화면 복귀

**전체 앱 흐름**

```
LoadingScreen
   → 위치/네트워크 요청
   → 완료 후 LocationScreen 이동

```

## 5️⃣ 화면 간 데이터 전달 방식 (강의 150)

**1) Navigator로 데이터 전달**

- LocationScreen의 생성자에 데이터를 전달
- 예: `LocationScreen(locationWeather: weatherData)`

**2) State 객체에서 widget 데이터 접근**

- StatefulWidget → State로 데이터 전달
- `widget.locationWeather` 로 접근

**3) updateUI() 역할**

- 날씨 값 분리하여
  `temperature / condition / cityName` 등 State에 저장
- UI 반영은 setState 안에서 진행

## 7️⃣ WeatherModel 중심 구조로 리팩토링 (강의 152)

**기존 문제**

- LoadingScreen 내부에서 위치 조회 + API 요청 처리
  → 재사용 어려움

**개선 방향**

- WeatherModel 내부에 다음 기능 이동:
  - 현재 위치 조회
  - API URL 생성
  - API 요청 실행

**장점**

- LocationScreen에서도 동일 기능 바로 재사용 가능
  (예: 새로고침 버튼)

**에뮬레이터 위치 문제**

- GPS 없음 → “수동으로 Lat/Lng 입력”해야 정상 동작
- Web 환경에서는 노트북 위치 정보 사용 → 정상 동작

**null 데이터 처리**

- 위치 꺼짐, 네트워크 오류 등으로 weatherData가 null일 수 있음
- updateUI() 시작부에서 null 체크로 앱 크래시 방지

## 8️⃣ CityScreen – 도시 직접 입력 기능 (강의 153)

**화면 전환 흐름**

- LocationScreen의 도시 아이콘 클릭 → CityScreen 이동

**TextField 구성**

- 배경 흰색, 둥근 테두리, hint 문구, 아이콘 포함
- 스타일은 `constants.dart`에서 `InputDecoration` 상수로 관리

**onChanged 기능**

- 사용자가 입력하는 도시명을 실시간으로 저장
- 이후 Navigator로 값을 반환해 API에 전달하는 구조 완성
